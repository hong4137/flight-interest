개인정보처리방침

Jintae namecard automation · 최종 수정일 2026년 9월 18일

본 도구는 명함 사진을 읽어 사용자의 구글 연락처에 등록하는 비상업적 개인용 도구입니다. 아래는 이 과정에서 다루는 정보와 그 취급 방식입니다.

1. 다루는 정보

  • 명함 이미지 — 사용자가 텔레그램 봇에 직접 전송한 사진
  • 명함에 적힌 정보 — 이름, 회사명, 부서, 직책, 전화번호, 팩스, 이메일, 주소, 홈페이지
  • 텔레그램 채팅 ID — 허용된 사용자인지 확인하기 위한 숫자 식별자

그 밖의 정보는 수집하지 않습니다.

2. 이용 목적

수집한 정보는 오직 사용자의 구글 연락처에 연락처 항목을 생성하는 목적으로만 사용합니다. 광고, 분석, 프로파일링, 모델 학습 등 다른 목적으로 사용하지 않습니다.

3. 보관

  • 명함 이미지는 처리 후 별도로 저장하지 않습니다.
  • 추출된 연락처 정보는 사용자 본인의 구글 계정에만 저장되며, 제작자는 사본을 보관하지 않습니다.
  • 텔레그램 채팅 ID와 구글 계정 접근 토큰은 접근 권한 유지를 위해 Google Apps Script의 스크립트 속성에 저장됩니다.

4. 제3자 제공

수집한 정보를 제3자에게 판매하거나 제공하지 않습니다. 처리 과정에서 아래 서비스를 경유합니다.

  • Telegram — 사진 전송 경로
  • Google (Gemini API, People API, Apps Script) — 텍스트 추출 및 연락처 저장

5. 구글 사용자 데이터

본 도구가 Google API로부터 받은 정보의 사용 및 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요건을 준수합니다.

사용하는 권한은 https://www.googleapis.com/auth/contacts 하나이며, 연락처 생성 외의 용도로는 사용하지 않습니다.

6. 권한 철회와 삭제

  • 구글 권한은 구글 계정 → 보안 → 서드 파티 앱에서 언제든 해제할 수 있습니다.
  • 이미 등록된 연락처는 사용자가 구글 연락처에서 직접 삭제할 수 있습니다.
  • 봇 사용 중단이나 저장된 채팅 ID 삭제는 아래 이메일로 요청하시면 처리합니다.

7. 아동

본 도구는 만 14세 미만 아동을 대상으로 하지 않습니다.

8. 변경

본 방침이 변경되면 이 페이지에 수정일과 함께 게시합니다.
